Ember Court — a playable card game (32-card deck, 4 houses, AI Rival, mouse + keyboard, WebAudio sound). `main.ts` (Node 22, standard library only, no network) copies `game/` and `screenshots/` to the output directory and writes `dossier.json`, the summary the judge reads.

## Run it

```sh
node main.ts
```

## Play it

```sh
node serve.ts
```

Then open http://localhost:8080
